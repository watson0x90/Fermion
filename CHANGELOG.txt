-= Fermion v2.0.0 =-

* Major revision. The app is rebuilt on a secured architecture with a new interface; scripts written for Frida 16 need small changes (see "Writing scripts for Frida 17" in the README)
* Architecture: all Frida work moved to the main process. The interface runs isolated (contextIsolation on, nodeIntegration off, @electron/remote removed) and reaches Frida only through an allow-listed bridge; arguments are validated in the main process
* Interface rewritten in React + TypeScript (Redux Toolkit, bundled with esbuild): custom title bar, collapsible activity rail, Session sidebar, tabbed toolbox (Editor, REPL, Graph, Process tree, Inspector), Output pane and status bar. jQuery and Semantic UI are gone from the main window
* The Device, Process, Instrument and Trace pop-up windows are replaced by the Session sidebar and the Graph tab
* Output: xterm-based terminal coloured by kind (LOG, WARN, ERR, MSG, STATUS) with filter chips, follow tail, clear, save, and search-as-you-type with a regex toggle, a clear button and search history
* Output can be detached into its own window and docked back, keeping history, filters and theme
* 16 colour themes that restyle the whole app (editor, output, panels, window frame); the original look, Kuroir, is the default
* New: REPL. Evaluate JavaScript in the attached process, with history, Tab completion and "help <name>" showing Frida's own documentation (generated from the Frida type definitions at build time)
* New: Process tree. Parent/child hierarchy with filter, collapse, attach from a row, and "only ancestry"
* New: Inspector (read-only). Modules with exports/imports; Memory with ranges, hex view and byte/text scan; Threads with registers and symbolized backtrace
* Graph: tracing works again on Frida 17 (it used a removed API). The tracer now keeps every batch of calls, draws a call graph of functions with repeat counts, leaves out Frida's own calls, samples hot functions and caps large graphs. The graph is shown as an image, with zoom, fit and save-as-SVG
* Editor: Reload button in the toolbar; a failed reload is reported in Output
* Session: a remote frida-server can be added by host:port from the sidebar
* Fix: process parent PID, user and path were silently dropped on Frida 17 (ppid is a BigInt)
* Fix: the status bar could be painted over after resizing the window
* Fix: re-rendering the output (toggling a filter) duplicated every line
* Examples updated to the Frida 17 export-lookup API
* Bundled API docs page marked as predating Frida 17
* Tests: Vitest component tests, node:test unit tests for the main process and the in-target helper scripts, and Playwright end-to-end tests that drive the real app (smoke, terminal, toolbar, detach, process tree, REPL, inspector, graph, attach). CI runs them on every push

-= Unreleased (after v2.0.0) =-

* Graph: tracing works again on Frida 17 (see the v2.0.0 notes; this landed just before the release)
* Editor: the toolbar shows the script's file name and marks unsaved changes; Open, Save, Save As and a Recent files menu. Opening over unsaved changes asks first
* Fix: saving the Output log or a graph became "the current file", so the next Ctrl-S wrote the script over it
* REPL: a running entry can be cancelled (button or Esc); listed completions can be walked with the arrow keys and accepted with Enter or Tab
* Inspector: follow a thread with Stalker and list the functions it called, most-called first; Auto-refresh on the Threads list and the Memory hex view
* Inspector, Follow: choose what is followed (everything, everything but system libraries, or one module) so the thread runs faster and the result is less noisy; filter the result, group it by module with per-module totals, and save it as CSV
* Output: search history is remembered between sessions; output is relayed to the detached window in batches instead of one message per line
* About and Docs windows follow the colour theme. Docs is now a searchable reference generated from the installed Frida's type definitions, replacing the hand-copied pre-17 documentation. jQuery and Semantic UI are no longer loaded
* Housekeeping: ESLint warnings 75 -> 0; GitHub Actions checkout/setup-node v4 -> v5; the release archive stores symlinks instead of following them (the macOS package was inflated); package.json points at this repository
* Tests: end-to-end tests for the Editor's file handling and the dialogs; every test script now runs in a temporary profile
* Hooks tab: find functions (exports, imports, debug symbols) and hook them without writing a script. Each hook has its own handler, an on/off switch and a call count; calls are listed with thread, depth and callers. Hooks survive script reloads and are placed again after a detach + attach
* Inspector: Disassembly view (instructions at an address, follow calls and jumps, Back, More). Right-click any address in Fermion for a menu: copy, open in Memory, open in Disassembly, hook it
* Spawn: environment variables, working directory, quoted arguments with spaces, and Start suspended with a Resume button; hooks are placed before a spawned program runs. A failed spawn is reported instead of failing silently
* When a session ends the sidebar says why and offers Spawn again / Attach again
* REPL: object and array results are an expandable tree; pointers in a result open the address menu
* Catch child processes: a process started by the attached process is held before it runs; switch the session to it (script and hooks in place first, optionally kept suspended) or let it run
* Hooks are saved and restored when Fermion is opened again
* Bookmarks: save any address from the address menu, with a name and a note; kept by module and offset, saved automatically, listed under Inspector > Bookmarks
